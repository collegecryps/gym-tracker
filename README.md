# Gym Tracker

A home-screen web app for a lean bulk: log food (with photo estimates), lifts and bodyweight.
Calorie targets adjust to your real weight trend, and lifting advice follows published research
(sources are listed in the app under More).

Data stays on each phone. Photo recognition uses your own free Google Gemini key, entered in the app.

## Install on iPhone

Open the site in Safari, tap Share, then Add to Home Screen.

## Develop

```
npm install
npm run dev
npm test
```
